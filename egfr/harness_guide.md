# harness_guide.md — 과제 계약서 (전반부)

이 문서는 **이번 과제에서만 유효한 계약**입니다.
환경 설정과 복구 절차는 `CLAUDE.md`에 있으며, 이 문서는 "무엇을 만들 것인가"만 규정합니다.

빈칸은 두 종류입니다.

- `[ ]` — **시작 전에 사람이 직접** 채웁니다. 데이터를 보지 않아도 정할 수 있는 것입니다.
- `[결정 후 기록]` — 데이터를 본 뒤에 정합니다. Claude가 제안 → 사람이 승인 → 이 문서에 기록합니다.

## 5. 하네스 제약 — 수정 금지

이 절은 학생이 수정하지 않습니다. 팀 규모를 여기서 고정합니다.

| 항목 | 개수 | 역할 |
|---|---|---|
| 공통 스킬 | 1 | 파이프라인 공통 규칙 강제 (seed · 분할 비율 · 저장 경로 · 기록 형식) |
| 서브에이전트 | 4 | 아래 표 |

| 서브에이전트 | 실행 위치 | 책임 |
|---|---|---|
| orchestrator | 로컬 | 전체 흐름 감독, 각 단계 위임, 진행 보고 |
| preprocess | 로컬 | 데이터 수집 · 정제 · 분할 |
| train-dl | Colab GPU | 모델 학습, 가중치 저장 |
| evaluate | 로컬 | 지표 계산 · 비교 · 최선 모델 선정 |

- 개수를 늘리거나 줄이지 않습니다.
- 이름은 달라질 수 있으나 **역할 분담은 위 표를 따릅니다.**
- 학습 이외의 작업을 Colab에서 수행하지 않습니다.
